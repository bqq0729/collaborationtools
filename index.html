사용 통계

테스트 화면 만들기

학습된 모델을 웹 화면에서 바로 써 보는 도구. 여러 화면을 탭으로 나눠 한 화면에 둘 수 있습니다.

지도 · 3D 가시화 라이브러리

항적·탐지 범위를 지도와 3D로 직접 그리는 웹 라이브러리. 시뮬레이터·시연 화면을 만들 때 씁니다.

항적 · 센서 데이터 시각화

개발 없이 바로 쓰는 도구. 예측 항적과 실제 항적을 지도·3D·시간축으로 비교합니다.

지도 배경은 외부 지도 서비스에서 불러오므로 인터넷이 안 되는 서버는 오프라인 지도가 필요합니다(MapLibre + 자체 지도 서버 등). 항적 위치가 민감하면 보안 규정을 확인하세요.
