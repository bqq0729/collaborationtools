# 협업 도구 정리

> 요즘 AI 모델도, 협업 도구도 너무 많아서 뭘 써야 할지 모르겠죠?
> 그래서 Claude에게 부탁해 **AI · 협업 도구를 기준별로 한눈에 비교하는 사이트**를 만들었습니다.

**사이트 보기:** https://bqq0729.github.io/collaborationtools/

설치 없이 HTML 파일 하나로 동작합니다. 브라우저로 열면 바로 볼 수 있어요.

## 무엇을 할 수 있나요?

| 탭 | 내용 |
|---|---|
| **조합 만들기** | 기준(무료 · 최소 비용 · 효율성 · 사내 보관 · 쉬운 사용 · 도구 하나로)을 고르면 일감 · 문서 · 코드 · 테스트 도구가 자동으로 채워집니다. 인원과 결제 방식(월 / 연)에 맞춰 비용을 계산하고, 6가지 조합을 표로 비교합니다. 결과는 PDF로 저장할 수 있습니다. |
| **역할별 도구** | 일감 관리, 문서 관리, 코드 · 이슈 관리, 테스트 · 품질 관리별 추천 도구, 요금, 장단점, 대체 도구 |
| **ML·DL 협업 도구** | MLflow, W&B, ClearML 등 실험 기록 · 모델 관리 도구를 실제 화면과 함께 비교 |
| **모델 테스트 도구** | Gradio, Streamlit, Dash 등 학습한 모델을 웹 화면에서 바로 써 보는 도구 |
| **가시화 도구** | CesiumJS, deck.gl, Three.js, Mapbox GL JS, MapLibre GL JS 등 지도 · 3D 시각화 라이브러리와 Kepler.gl, Foxglove 같은 데이터 시각화 도구 |
| **AI 협업 도구** | Claude, ChatGPT, Gemini, GitHub Copilot과 협업 도구 안에 들어 있는 AI 기능 비교, 개발자 AI 사용 통계 |
| **링크 모음** | 페이지에 나온 모든 서비스의 공식 사이트 · 요금제 링크 |

각 탭에는 Stack Overflow 개발자 설문, PyPI 다운로드 수, GitHub 스타 같은 **실제 사용률 통계**가 함께 들어 있습니다.

## 참고

- 요금 · 통계는 **2026년 10월 기준**입니다. 원화는 1달러 = 1,400원, 부가세 별도로 계산했습니다. 도입 전에는 각 공식 사이트에서 최신 요금을 꼭 확인하세요.
- 도구 화면 사진은 각 도구의 공식 문서 · GitHub에서 불러오므로 인터넷 연결이 필요합니다.
